# TryHackMe Activity Log

## OWASP Top 10 2025: IAAA Failures

### What I Learned

- Weak authentication, authorisation and access controls can allow attackers to gain unauthorised access.
- Security testing can identify account and permission weaknesses before attackers exploit them.

### Evaluation

This activity demonstrated how penetration testing can identify access control weaknesses. However, it focused primarily on web application vulnerabilities rather than wider organisational security.


## OWASP Top 10 2025: Application Design Flaws

### What I Learned

- Security vulnerabilities can be introduced during software design.
- Poor planning can create security issues before code is written.

### Evaluation

This activity showed that penetration testing can identify design flaws, but also highlighted the importance of secure development practices.


## OWASP Top 10 2025: Insecure Data Handling

### What I Learned

- Sensitive data must be handled securely.
- Data protection is an essential component of cybersecurity.

### Evaluation

This activity demonstrated that penetration testing can help identify data-security weaknesses but should be supported by wider security policies.


## Offensive Security Intro

### What I Learned

- Penetration testers simulate attacks in a legal and controlled environment.
- Ethical hackers identify vulnerabilities before malicious actors can exploit them.
- Permission and responsible disclosure are essential.

### Evaluation

This was one of the most valuable activities because it clearly demonstrated the role and purpose of penetration testing.


## Defensive Security Intro

### What I Learned

- Organisations use monitoring and incident response to defend systems.
- Cybersecurity requires both preventative and reactive measures.

### Evaluation

This activity showed that penetration testing is only one part of a wider security strategy.


## Nmap

### What I Learned

- Nmap can identify devices, services and open ports.
- Nmap is a common reconnaissance tool.

### Evaluation

This activity provided practical insight into how penetration testers gather information before conducting assessments.
